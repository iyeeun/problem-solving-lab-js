### 2026-10-07

#### 📌 오늘 한 내용

- 프로그래머스 AI 추천 문제를 풀었음
- 1단계 문제들을 풀었음 (문제 풀이 기록은 하지 않음)

#### 🧠 배운 내용

- 두 구간은 `첫 번째 시작 <= 두 번째 끝`이고 `첫 번째 끝 >= 두 번째 시작`일 때 겹침
- 10진수 -> 2진수 변환: `toString(2)`
- 서로 인접한 두 연속 구간을 비교할 때는 두 구간 사이의 경계를 고정한 뒤 양쪽으로 확장하면 후보를 빠짐없이 확인할 수 있음

#### 🔁 실수 패턴

- 밀리초 문자열을 숫자로 변환하지 않아 `endTime` 계산에서 숫자 덧셈 대신 문자열 연결이 발생했음

### 2026-10-14

#### 📌 오늘 한 내용

- 프로그래머스 Level 1 문제들을 풀었음

#### 🧠 배운 내용

- 변환할 문자열이 정해져 있으면 객체에 변환 전후 값을 저장하고 `Object.entries`로 순회할 수 있음
- `localeCompare`를 사용하면 문자열의 사전순 비교 결과를 정렬 비교 함수에 바로 사용할 수 있음
  - `a.localeCompare(b)`는 a가 사전순으로 앞서면 음수, 같으면 0, 뒤면 양수를 반환하므로 문자열 정렬 비교 함수에 바로 사용할 수 있음
