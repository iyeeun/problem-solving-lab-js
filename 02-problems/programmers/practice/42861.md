# [섬 연결하기](https://school.programmers.co.kr/learn/courses/30/lessons/42861)

## 문제 요약

- n개의 섬을 다리로 연결해야 함
- 모든 섬이 서로 통행할 수 있어야 함
- 모든 섬을 연결하는 데 필요한 최소 비용을 구하는 문제
- 직접 연결되지 않아도 다른 섬을 거쳐 도달할 수 있으면 연결된 것으로 봄

## 입력 구조

- n: 섬의 개수, 1 이상 100 이하
- costs: `[섬1, 섬2, 연결 비용]` 형태의 2차원 배열
- 같은 두 섬 사이의 연결은 한 번만 주어짐
- 모든 섬을 연결할 수 있는 입력만 주어짐

## 문제 유형 분류

- Greedy
- 그래프
- 최소 신장 트리(MST)
- 크루스칼 알고리즘
- Union-Find

## 사고 과정

### 1. 왜 이 유형인가

- 모든 노드를 연결하면서 전체 간선 비용을 최소화해야 하므로 MST임
- 비용이 낮은 간선부터 선택하는 Greedy 방식인 크루스칼 알고리즘을 사용할 수 있음
- 간선을 선택할 때 사이클이 생기는지 빠르게 확인하기 위해 Union-Find를 사용함

### 2. 왜 다른 접근은 안되는가

- DFS/BFS: 연결 여부는 확인할 수 있지만 어떤 간선을 선택해야 비용이 최소가 되는지는 결정할 수 없음
- 완전탐색: 가능한 간선 조합을 모두 확인하면 경우의 수가 너무 많음
- Prim 알고리즘: 사용할 수 있지만 이 풀이에서는 간선 목록이 주어지므로 크루스칼 방식으로 해결함

## 문제 풀이

- [42861.js (7분 소요)](./42861.js)

```
1. 각 섬이 자기 자신을 대표로 가지도록 parent 배열을 초기화함
2. 각 집합의 크기를 저장하는 size 배열을 1로 초기화함
3. costs를 다리 건설 비용 기준으로 오름차순 정렬함
4. 비용이 낮은 간선부터 확인함
5. 두 섬이 서로 다른 집합이면 union으로 합치고 해당 비용을 answer에 더함
6. 이미 같은 집합이면 사이클이 생기므로 해당 간선을 선택하지 않음
```

## 해결 전략

### 알고리즘 선택 이유

- 크루스칼 알고리즘은 비용이 낮은 간선부터 확인하며 사이클을 만들지 않는 간선만 선택함
- 서로 다른 두 연결 요소를 합칠 때마다 최소 비용으로 연결 범위를 확장할 수 있음
- 모든 섬이 하나의 집합이 되면 최소 신장 트리가 완성됨

### 자료구조 선택 이유

- `parent` 배열: 각 노드의 부모를 저장하고 집합의 대표를 찾는 데 사용
- `size` 배열: 작은 트리를 큰 트리 아래에 붙여 트리의 높이를 낮추는 데 사용
- Union-Find: 두 섬이 이미 연결되어 있는지 빠르게 확인하고 서로 다른 집합을 합침

### union 반환값 활용

```javascript
if (!union(s, e)) continue;
answer += c;
```

- `union(s, e) === true`: 서로 다른 두 집합이 합쳐졌으므로 간선을 선택함
- `union(s, e) === false`: 이미 같은 집합이므로 해당 간선을 선택하면 사이클이 생김
- 사이클을 만들지 않는 간선만 비용에 포함함
- 선택되는 간선은 최대 `n - 1`개이며, 그 이후의 `union`은 모두 실패하므로 별도의 개수 검사가 없어도 정답에는 영향 없음

## 시간/공간 복잡도

- E는 `costs.length`
- 시간: O(E log E)
  - 간선 정렬: O(E log E)
  - Union-Find 연산: O(E α(n)), 정렬보다 작음
- 공간: O(n)
  - `parent`, `size` 배열 사용

## JS 구현 포인트

- 숫자를 기준으로 정렬하기 위해 비교 함수를 전달함

  ```javascript
  costs.sort((a, b) => a[2] - b[2]);
  ```

- 섬 번호가 `0 ~ n - 1`이므로 배열 길이를 `n`으로 초기화함

  ```javascript
  const parent = Array.from({ length: n }, (_, i) => i);
  ```

- `find`에서 경로 압축을 적용함

  ```javascript
  parent[x] = find(parent[x]);
  ```

- Union by Size를 적용하기 위해 작은 집합이 `rootA`가 되도록 교환함

  ```javascript
  if (size[rootA] > size[rootB]) {
    [rootA, rootB] = [rootB, rootA];
  }

  parent[rootA] = rootB;
  size[rootB] += size[rootA];
  ```

- MST에서는 n - 1개의 edge를 선택하면 종료되므로 해당 조건을 추가하여 더 최적화할 수 있음
