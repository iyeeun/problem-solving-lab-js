# [아이템 줍기](https://school.programmers.co.kr/learn/courses/30/lessons/87694)

## 문제 요약

- 겹쳐진 직사각형들로 이루어진 다각형 지형이 주어지고, 캐릭터는 이 다각형의 둘레(테두리)를 따라서만 이동 가능
- 사각형이 겹쳐서 중앙에 빈 공간(구멍)이 생기더라도, 캐릭터가 다닐 수 있는 길은 가장 바깥쪽 테두리뿐임
- 캐릭터 위치에서 아이템 위치까지 테두리를 따라 이동하는 최단 거리를 구하는 문제

## 입력 구조

- rectangle: 직사각형 정보 배열([x1, y1, x2, y2] 형태), 1개 이상 4개 이하
- characterX, characterY: 캐릭터의 초기 위치 좌표
- itemX, itemY: 아이템의 위치 좌표
- 좌표값: 1 이상 50 이하
- 서로 다른 두 직사각형은 x축 또는 y축 좌표가 겹치지 않음
- 캐릭터와 아이템은 항상 다각형 테두리 위의 점이고, 서로 위치가 같지 않음

## 문제 유형 분류

- BFS
- 그래프 탐색(최단거리)
- 좌표 스케일링

## 사고 과정

### 1. 왜 이 유형인가

- 겹친 사각형들의 합집합 모양 둘레를 정점 좌표로 직접 계산하는 대신, 격자 위의 점들 중 "테두리에 해당하는 점"만 골라내고 그 점들 사이를 BFS로 탐색하는 방식이 구현이 훨씬 단순함
- 좌표 범위가 1~50으로 작아서 격자 전체를 순회하는 접근이 시간/공간 모두 충분히 감당 가능

### 2. 왜 다른 접근은 안되는가

- 정점 좌표를 직접 계산해 다각형을 구성: 사각형이 겹치는 패턴(변이 맞닿는 경우, 한 사각형이 다른 사각형에 완전히 덮이는 경우 등)이 다양해서 예외 처리가 매우 복잡해짐
- 원래 좌표를 그대로 쓰는 격자: 두 사각형이 정확히 변을 맞대고 있는 지점처럼 "이 점이 진짜 테두리인지 안쪽인지"가 애매해지는 경우가 있어, 좌표를 2배로 스케일링해서 반 칸 단위까지 다뤄야 이 애매함이 해소됨

## 문제 풀이

- [87694.js (60분+ 소요)](./87694.js)

```
- 모든 좌표를 2배로 스케일링해서 반 칸 단위까지 정수 좌표로 다룸 (LIMIT = 110짜리 2차원 배열 arr, dist)
- 1단계: 각 사각형에 대해 (2*x1 ~ 2*x2, 2*y1 ~ 2*y2) 범위 전체(테두리 포함)를 arr에 1로 마킹
- 2단계: 각 사각형에 대해 순수 내부(테두리 제외, 2*x1+1 ~ 2*x2-1, 2*y1+1 ~ 2*y2-1)만 다시 0으로 지움
  - 이 두 단계를 거치면 어떤 사각형 하나의 순수 내부에만 속하는 점은 0이 되고, 테두리이거나 다른 사각형과 겹치는 경계에 걸친 점만 1로 남음
  - 사각형에 완전히 파묻힌 사각형의 테두리도 자동으로 0 처리되고, 중앙에 구멍이 생기는 경우에도 그 구멍의 안쪽 테두리는 어느 사각형의 테두리도 아니므로 자연스럽게 1로 남지 않음
- BFS: 캐릭터 위치(2배 스케일)에서 시작해 상하좌우로 한 칸씩 이동하면서 arr가 1인 점만 방문, dist에 거리를 기록
- 큐에서 꺼낸 점이 아이템 위치와 같으면 즉시 종료
- 최종 dist 값은 반 칸 단위이므로 2로 나눠서 원래 좌표 단위의 최단 거리로 반환
```

## 해결 전략

### 알고리즘 선택 이유

- 모든 이동 간선의 가중치가 1인 격자 그래프에서의 최단 거리 문제라 BFS로 충분
- 테두리 판별을 그래프 구성 전 단계(마킹)에서 미리 끝내 놓아서, BFS 자체는 단순한 격자 최단거리 탐색으로 남겨둠

### 자료구조 선택 이유

- 2차원 배열(arr, dist): 좌표를 인덱스로 바로 접근할 수 있어 점 단위 마킹과 방문 여부 확인에 적합
- 배열 기반 큐 + head 포인터: BFS의 선입선출 순서를 유지하면서 shift()의 O(n) 비용 없이 O(1)로 dequeue

## 시간/공간 복잡도

- 좌표 최댓값을 M(=50), 사각형 개수를 R(<=4)이라 하면
- 시간: O(R \* M^2 + M^2), 사각형별 마킹에 O(M^2)씩 R번, BFS는 전체 격자(2M x 2M)를 최대 한 번씩 순회
- 공간: O(M^2), arr와 dist 배열이 (2M+buffer) x (2M+buffer) 크기로 고정

## JS 구현 포인트

- 좌표를 2배로 스케일링해서 원래 좌표계에서는 표현 못 하는 "변이 맞닿는 지점"까지 정수 좌표로 다룸
- 전체를 1로 채운 뒤 사각형별 순수 내부만 다시 0으로 지우는 2단계 마킹으로, 별도의 "바깥 공간과 연결됐는지" 확인 로직 없이도 겹침/포함/구멍 케이스를 한 번에 처리
- BFS 이동은 dx/dy 배열로 상하좌우 4방향만 사용하고, 대각선 이동은 쓰지 않음
- 배열 큐 + head 포인터 방식으로 shift() 없이 큐를 구현
- 반환 직전 거리를 2로 나눠 스케일링을 원상 복구
