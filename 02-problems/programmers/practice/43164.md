# [여행경로](https://school.programmers.co.kr/learn/courses/30/lessons/43164)

## 문제 요약

- 주어진 항공권을 모두 이용해서 여행 경로를 짜는 문제, 항상 ICN 공항에서 출발
- 여러 경로가 가능하면 알파벳 순서가 앞서는 경로를 반환
- 모든 도시를 방문할 수 없는 경우는 주어지지 않음

## 입력 구조

- tickets: [a, b] 형태의 항공권 배열, a에서 b로 가는 편을 의미
- 공항은 대문자 3글자로 구성
- 항공권 개수: 1 이상 10000 이하
- 모든 항공권을 반드시 한 번씩 사용

## 문제 유형 분류

- DFS
- 백트래킹
- 그래프 탐색(오일러 경로)

## 사고 과정

### 1. 왜 이 유형인가

- 항공권 하나하나가 간선이고 공항이 노드인 그래프에서, 모든 간선을 정확히 한 번씩 사용하는 경로(오일러 경로)를 찾는 문제
- 알파벳 순서가 앞서는 경로를 우선해야 하므로, tickets를 미리 정렬해두고 앞에서부터 탐색하면 처음 찾은 완성 경로가 곧 최적 경로가 됨
- 중간에 잘못된 선택을 하면 되돌아가서 다른 간선을 시도해야 하므로 백트래킹(DFS + 사용 여부 되돌리기)이 필요

### 2. 왜 다른 접근은 안되는가

- Greedy(매번 알파벳이 앞선 도착지로만 진행): 당장 알파벳이 앞선 선택이 이후 모든 항공권을 다 쓰지 못하는 막다른 길로 이어질 수 있어, 되돌아가는 과정 없이는 실패
- BFS: 완성된 경로 하나(모든 티켓을 다 쓴 경로)를 찾아야 하는데, 상태를 "지금까지 사용한 티켓 집합 + 현재 위치"로 잡으면 상태 공간이 너무 커져 비효율적

## 문제 풀이

- [43164.js (60분+ 소요)](./43164.js)

```
- tickets를 정렬해서 같은 출발지에서 여러 후보가 있을 때 알파벳 순서가 앞선 것부터 시도되게 함
- used 배열로 이미 사용한 항공권을 표시
- dfs(idx, routes): idx번째 항공권을 마지막으로 사용한 상태에서, 지금까지의 경로(routes)를 이어감
  - routes.length가 tickets.length와 같아지면(모든 항공권을 다 씀) 그 routes를 반환
  - 그렇지 않으면 아직 안 쓴 항공권 중 출발지가 현재 도착지와 같은 것을 순서대로 시도
  - 그 중 하나라도 완성된 경로(res)를 반환하면 그 값을 그대로 위로 전달해서 탐색을 즉시 종료, 실패하면 used를 되돌리고 다음 후보 시도
- ICN에서 출발하는 항공권들을 순서대로 시작점 삼아 dfs를 호출하고, 완성된 경로를 찾으면 ICN을 앞에 붙여 반환
```

## 해결 전략

### 알고리즘 선택 이유

- 정렬 + DFS 백트래킹으로 "처음 찾은 완성 경로 = 알파벳 순서가 가장 앞선 경로"라는 성질을 이용, 별도의 경로 비교 없이 첫 성공 경로를 그대로 답으로 채택
- dfs가 완성된 routes를 반환하면 그 반환값을 호출 스택 전체로 그대로 전파시켜, answers 배열에 여러 결과를 모았다가 고르는 대신 탐색을 즉시 중단

### 자료구조 선택 이유

- used 배열: 항공권(간선) 단위로 사용 여부를 표시해 같은 티켓을 중복 사용하지 않도록 함
- 배열(routes): 현재까지의 경로를 그대로 들고 다니다가 완성되면 바로 반환

## 시간/공간 복잡도

- 항공권 개수를 T라 하면
- 시간: 정렬에 O(T log T), 최악의 경우 DFS 백트래킹이 여러 갈래를 재시도할 수 있어 이론상 O(T^2)에 가까움 (매 단계마다 최대 T개 후보를 순회)
- 공간: O(T), used 배열과 재귀 깊이, routes 배열 모두 항공권 개수에 비례

## JS 구현 포인트

- dfs가 완성된 경로를 찾으면 배열에 쌓아두는 대신 즉시 그 값을 return해서, 호출 스택을 타고 올라가며 `if (res) return res;`로 이후의 모든 반복문과 재귀 호출을 조기 종료
- tickets.sort()로 문자열 배열([a, b])을 기본 정렬하면 첫 번째 요소, 그다음 두 번째 요소 순으로 사전식 정렬되는 점을 이용해 알파벳 우선순위를 자연스럽게 반영
- used를 dfs 진입 시 true로 표시하고, 그 경로가 실패로 판명되면(`res`가 없으면) 다시 false로 되돌리는 전형적인 백트래킹 패턴 사용
