# [퍼즐 조각 채우기](https://school.programmers.co.kr/learn/courses/30/lessons/84021)

## 문제 요약

- 게임 보드의 빈 공간(0)에 테이블에서 떼어낸 퍼즐 조각(1로 이루어진 덩어리)을 채워 넣는 문제
- 조각은 회전 가능하지만 뒤집을 수는 없고, 새로 채운 조각이 인접한 빈 칸을 남기면 안 됨
- 채울 수 있는 조각들로 채워지는 칸의 총 개수를 구함

## 입력 구조

- game_board: 정사각 2차원 배열, 크기는 3 이상 50 이하
- game_board의 원소: 0(빈칸) 또는 1(채워진 칸)
- table: game_board와 동일한 크기의 정사각 2차원 배열
- table의 원소: 0(빈칸) 또는 1(퍼즐 조각)
- 하나의 퍼즐 조각은 1x1 정사각형이 1개 이상 6개 이하 연결된 형태

## 문제 유형 분류

- 완전탐색
- BFS (연결 요소 탐색)
- 도형 회전, 좌표 정규화

## 사고 과정

### 1. 왜 이 유형인가

- game_board의 빈 칸 덩어리(blank)들과 table의 조각 덩어리(piece)들 각각을 BFS로 찾아내는 연결 요소 탐색 문제
- 조각을 4방향(0/90/180/270도)으로 돌려본 모양들과 각 빈 공간의 모양을 비교해서 맞는 조합을 찾아야 하므로, 남은 조각들에 대해 맞는 것을 하나씩 찾아나가는 완전탐색이 필요

### 2. 왜 다른 접근은 안되는가

- 좌표를 그대로 두고 정점 목록을 비교: 같은 모양이라도 보드 안 위치가 다르면 좌표값 자체가 달라서 바로 비교가 안 되므로, 상대 좌표로 변환하는 과정(정규화)이 반드시 필요
- Greedy(크기순으로 정렬해서 순서대로 매칭): 크기가 같아도 모양이 다른 조각/빈칸이 여러 개 있을 수 있어서, 정렬 순서만 믿고 앞에서부터 짝지으면 실제로 맞는 조합을 놓칠 수 있음

## 문제 풀이

- [84021.js (60분+ 소요)](./84021.js)

```
- BFS로 game_board의 0 덩어리들을 blanks에, table의 1 덩어리들을 pieces에 각각 모음
- rotate(shape): 좌표 (x, y)를 (y, -x)로 바꿔 도형을 90도 회전시킴
- isFit(a, b): 두 도형의 좌표를 (행, 열) 기준으로 정렬한 뒤, 각각 정렬된 배열의 첫 좌표를 기준점 삼아 상대 좌표로 변환하고, 그 상대 좌표 목록이 완전히 같은지 비교
- used 배열로 이미 사용된 piece를 표시
- 각 blank마다 아직 안 쓴 piece를 순서대로 순회하면서, 크기가 같은 piece에 대해 원본과 90/180/270도 회전 버전 중 하나라도 isFit이 맞으면 그 piece를 사용 처리하고 blank의 칸 수만큼 answer에 더함
- 모든 blank에 대해 이 과정을 반복해 최종 answer 반환
```

## 해결 전략

### 알고리즘 선택 이유

- 조각의 개수가 최대 몇십 개 수준이고 보드 크기도 50 이하라 완전탐색(각 blank마다 남은 piece를 하나씩 다 시도)으로도 시간 내에 충분히 해결 가능
- 크기가 같은 조각이 여러 개 있어도 모양까지 정확히 비교해서 맞는 것만 매칭하므로, 정렬 후 순서대로 짝짓는 방식보다 안전하게 정확한 매칭을 보장

### 자료구조 선택 이유

- 배열(blanks, pieces): 각 덩어리를 좌표 목록으로 저장해 회전/비교 연산을 그대로 적용
- used 배열: 이미 매칭된 piece를 다시 사용하지 않도록 관리해서 하나의 물리적 조각이 여러 blank에 중복으로 쓰이는 것을 방지

## 시간/공간 복잡도

- 빈 칸/조각 덩어리 개수를 각각 B, P, 한 덩어리의 최대 칸 수를 K(<=6)라 하면
- 시간: BFS로 덩어리를 모으는 데 O(n^2), 매칭 과정은 O(B _ P _ K log K) (isFit마다 정렬 비용 O(K log K)가 들고, 회전 4가지를 시도)
- 공간: O(n^2), blankdist/piecedist 배열과 덩어리 좌표 목록 저장

## JS 구현 포인트

- isFit에서 좌표를 `(a[0]-b[0]) || (a[1]-b[1])` 형태의 숫자 비교 comparator로 정렬해서, 좌표에 두 자릿수나 음수가 섞여도 항상 올바른 순서로 정렬되도록 함
- used 배열을 pieces 인덱스 기준으로 관리해, 회전된 모양이 매칭에 성공해도 같은 인덱스의 piece 전체를 한 번만 사용하도록 처리
