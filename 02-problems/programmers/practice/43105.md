# [정수 삼각형](https://school.programmers.co.kr/learn/courses/30/lessons/43105)

## 문제 요약

- 삼각형의 꼭대기에서 바닥까지 이어지는 경로 중 거쳐간 숫자의 합이 가장 큰 경우를 찾는 문제
- 아래 칸으로 이동할 때는 대각선 방향으로 한 칸 오른쪽 또는 왼쪽으로만 이동 가능

## 입력 구조

- triangle: 삼각형을 이루는 2차원 배열
- 삼각형의 높이: 1 이상 500 이하
- 삼각형을 이루는 숫자: 0 이상 9999 이하의 정수

## 문제 유형 분류

- DP (2차원 dp, 상향식)

## 사고 과정

### 1. 왜 이 유형인가

- 각 위치까지의 최대 경로 합은 바로 위 두 위치(대각선 왼쪽, 대각선 오른쪽)의 최대 경로 합 중 큰 값에 현재 칸의 값을 더한 것으로 결정됨
- 작은 부분 문제(윗 행까지의 최대 합)의 답을 그대로 재사용해 전체 답을 구할 수 있는 최적 부분구조를 가짐 -> DP

### 2. 왜 다른 접근은 안되는가

- 완전탐색(모든 경로를 다 시도): 경로 수가 삼각형 높이에 따라 지수적으로 늘어나 높이 500에서는 불가능
- Greedy(매 단계 더 큰 값을 선택): 지금 당장 큰 값이 다음 행에서 더 작은 값으로 이어질 수 있어 지역 최적이 전체 최적을 보장하지 않음

## 문제 풀이

- [43105.js (11분 소요)](./43105.js)

```
- dp[i][j]: triangle의 i번째 행 j번째 열까지 도달했을 때의 최대 경로 합
- dp[0][0]을 triangle[0][0]으로 초기화
- 각 행 i의 j마다 대각선 위 두 값(dp[i - 1][j - 1], dp[i - 1][j]) 중 큰 값에 triangle[i][j]를 더해 dp[i][j] 계산
- 범위를 벗어난 인덱스는 undefined이므로 || 0으로 0 처리해 경계를 그대로 계산에 포함
- 마지막 행 dp[triangle.length - 1] 중 최댓값을 반환
```

## 해결 전략

### 알고리즘 선택 이유

- 각 위치의 최대 합이 바로 위 두 위치의 최대 합에만 의존하므로, 위 행부터 아래 행 순서로 값을 누적하는 DP로 해결
- 이미 구해둔 행의 값을 그대로 재사용하므로 중복 계산이 없음

### 자료구조 선택 이유

- 2차원 배열(dp): 삼각형과 동일한 모양으로 각 위치의 최대 경로 합을 저장

## 시간/공간 복잡도

- n을 triangle.length라 하면
- 시간: O(n^2), 전체 원소 수(n \* (n + 1) / 2)만큼 한 번씩 계산
- 공간: O(n^2), dp 배열이 triangle과 동일한 크기로 생성됨

## JS 구현 포인트

- Array.from으로 각 행의 길이가 다른(i + 1칸) 배열을 만들어 삼각형 모양을 그대로 표현
- 범위를 벗어난 인덱스(dp[i - 1][-1], dp[i - 1][i])는 undefined가 되므로 || 0으로 처리해 경계를 별도 분기 없이 계산
- dp의 최솟값이 0이라 || 0을 써도 실제 0과 undefined가 섞여 결과가 달라지지 않음
- Math.max(...dp[triangle.length - 1])로 스프레드 문법을 이용해 마지막 행의 최댓값을 구함
