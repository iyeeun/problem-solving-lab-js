# [지형 이동](https://school.programmers.co.kr/learn/courses/30/lessons/62050)

## 문제 요약

- 핵심 요구사항
- N x N 격자에 각 칸의 높이가 주어지는데, 상하좌우로 이동할 때 높이 차이가 height를 초과하면 두 칸 사이에 사다리를 설치해야 함
- 모든 칸을 서로 이동할 수 있도록 만들기 위한 사다리 설치 비용의 최솟값 구하기

## 입력 구조

- land: N x N 크기의 2차원 배열
- land[i][j]: (i, j) 칸의 높이
- N: 1 이상 300 이하
- height: 1 이상 10^7 이하

## 문제 유형 분류

- BFS
- Union-Find (MST)

## 사고 과정

### 1. 왜 이 유형인가

- 특정 조건에 따라 노드 그룹화하기 -> BFS
- 각 그룹에 대해 최소 비용으로 연결하기 -> MST

### 2. 왜 다른 접근은 안되는가

- 각 영역마다 가장 싼 사다리만 선택하면 전체적으로 사이클이 생기거나 특정 영역이 중복 연결될 수 있으므로 아님

## 문제 풀이

- [62050.js (84분 소요)](./62050.js)

```
1. 모든 칸을 순회하며 방문하지 않은 칸에 대해 BFS를 수행 (높이 차이가 height 이하면 이동)
2. BFS 과정에서 높이 차이가 height를 초과하는 인접 칸은 사다리가 필요한 후보이므로 저장함
3. 저장해둔 사다리 후보에서 서로 다른 group을 연결하는 간선을 만듦
4. 간선을 사다리 비용이 작은 순서대로 정렬
5. Union-Find를 이용해 Kruskal 알고리즘을 수행
6. 모든 영역이 연결되었을 때의 비용 반환
```

## 해결 전략

### 알고리즘 선택 이유

- 영역 번호 부여 -> BFS
- 최소 비용으로 모든 영역 연결 -> 크루스칼

### 자료구조 선택 이유

- visited: 단순히 방문 여부만이 아닌 영역 변호를 저장하기 위해 배열 사용
- q: 배열을 큐처럼 사용, shift 대신 인덱스로 접근

## 시간/공간 복잡도

- 시간: O(N^2 log N^2) => O(N^2 log N)
- 공간: O(N^2)

## JS 구현 포인트

- BFS Queue에서 shift() 대신 target++ 방식으로 head index 관리
