# [귤 고르기](https://school.programmers.co.kr/learn/courses/30/lessons/138476)

## 문제 요약

- 수확한 귤 중 k개를 골라 한 상자에 담음
- 선택한 귤을 크기별로 분류했을 때 서로 다른 크기 종류의 최솟값을 구함

## 입력 구조

- k: 한 상자에 담을 귤의 개수, 1 이상 tangerine의 길이 이하
- tangerine: 귤의 크기를 담은 배열, 길이는 1 이상 100000 이하
- tangerine의 원소: 귤의 크기, 1 이상 10000000 이하

## 문제 유형 분류

- Greedy
- 해시
- 정렬

## 사고 과정

### 1. 왜 이 유형인가

- 같은 크기의 귤을 많이 선택할수록 적은 종류만으로 k개를 채울 수 있음
- 크기별 개수를 센 뒤 개수가 많은 종류부터 선택하면 매 선택마다 가장 많은 귤을 확보할 수 있음
- 누적 개수가 k 이상이 되는 순간까지 선택한 종류의 수가 최솟값임

### 2. 왜 다른 접근은 안되는가

- 귤의 크기 자체를 기준으로 정렬하거나 선택하면 각 크기의 등장 횟수를 반영할 수 없음
- 가능한 귤 조합을 직접 확인하면 배열의 길이가 최대 100000이므로 경우의 수가 너무 많음

## 문제 풀이

- [138476.js (7분 소요)](./138476.js)

```
1. Map에 귤의 크기별 등장 횟수를 저장함
2. Map의 항목을 등장 횟수 기준 내림차순으로 정렬함
3. 등장 횟수가 많은 크기부터 누적하면서 선택한 종류의 수를 증가시킴
4. 누적 개수가 k 이상이 되면 반복을 종료하고 종류의 수를 반환함
```

## 해결 전략

### 알고리즘 선택 이유

- 한 종류를 선택할 때 확보할 수 있는 귤의 수가 많을수록 필요한 종류의 수가 줄어듦
- 따라서 아직 선택하지 않은 종류 중 등장 횟수가 가장 많은 종류를 우선하는 그리디 선택이 최적임

### 자료구조 선택 이유

- Map을 사용하면 귤의 크기를 키로, 등장 횟수를 값으로 저장해 한 번의 순회로 빈도를 계산할 수 있음
- Map의 항목을 배열로 변환하면 등장 횟수를 기준으로 정렬하고 순서대로 순회할 수 있음

## 시간/공간 복잡도

- 시간: 귤의 개수를 n, 서로 다른 크기의 수를 m이라 할 때 빈도 계산 O(n), 정렬 O(m log m)이므로 O(n + m log m)
- 공간: 크기별 등장 횟수와 정렬 배열을 저장하므로 O(m)

## JS 구현 포인트

- `map.get(t) || 0`으로 해당 크기가 처음 등장한 경우의 기본값을 0으로 처리함
- 전개 문법으로 Map의 항목을 배열로 변환한 뒤 두 번째 원소인 등장 횟수를 기준으로 내림차순 정렬함
- 구조 분해 할당으로 각 항목의 크기와 등장 횟수를 분리해 순회함
