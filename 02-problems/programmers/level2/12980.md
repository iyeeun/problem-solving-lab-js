# [점프와 순간 이동](https://school.programmers.co.kr/learn/courses/30/lessons/12980)

## 문제 요약

- 현재 위치에서 K칸 앞으로 점프하면 건전지를 K만큼 사용함
- 현재까지 이동한 거리의 2배 위치로 순간 이동하면 건전지를 사용하지 않음
- 거리 n에 도달하기 위해 필요한 건전지 사용량의 최솟값을 구함

## 입력 구조

- n: 이동하려는 거리, 1 이상 1000000000 이하

## 문제 유형 분류

- Greedy
- 수학
- 비트 연산

## 사고 과정

### 1. 왜 이 유형인가

- 도착 지점 n에서 출발 지점 0으로 거꾸로 이동하면 선택을 단순하게 만들 수 있음
- n이 짝수이면 마지막 이동을 비용이 없는 순간 이동으로 보고 n을 2로 나눌 수 있음
- n이 홀수이면 순간 이동만으로 도달할 수 없으므로 최소 1칸의 점프가 필요함
- 홀수에서 1을 빼고 2로 나누는 과정을 반복하면 필요한 1칸 점프의 최소 횟수를 구할 수 있음

### 2. 왜 다른 접근은 안되는가

- 처음에는 각 위치까지 필요한 최소 건전지 사용량을 구하는 DP로 접근했으나 효율성 테스트를 통과하지 못함
- n이 최대 1000000000이므로 위치마다 값을 계산하고 저장하는 DP는 O(n)의 시간과 공간이 필요해 사용할 수 없음
- 역방향에서는 매 단계마다 거리가 절반으로 줄어들어 모든 위치를 확인할 필요가 없음

## 문제 풀이

- [12980.js (9분 소요)](./12980.js)

```
1. 도착 거리 n에서 0을 향해 역방향으로 이동함
2. n이 짝수이면 마지막 이동이 순간 이동인 것으로 보고 n을 2로 나눔
3. n이 홀수이면 1칸 점프가 필요하므로 건전지 사용량을 1 증가시킴
4. 홀수에서 1을 뺀 뒤 2로 나누는 과정을 Math.floor(n / 2)로 처리함
5. n이 0이 될 때까지 반복하고 사용한 건전지의 양을 반환함
```

## 해결 전략

### 알고리즘 선택 이유

- 짝수 거리는 직전 위치에서 순간 이동한 것으로 처리하는 것이 건전지를 사용하지 않으므로 항상 유리함
- 홀수 거리는 순간 이동으로 만들 수 없으므로 최소 1의 점프 비용이 반드시 필요함
- 각 단계에서 비용 없는 순간 이동을 최대한 활용하면서 필요한 1칸 점프만 세면 최솟값을 구할 수 있음

### 자료구조 선택 이유

- 현재 거리 n과 누적 건전지 사용량만 있으면 되므로 별도의 자료구조가 필요하지 않음
- n을 직접 갱신하면서 역방향 이동 상태를 표현함

## 시간/공간 복잡도

- 시간: 반복할 때마다 n이 절반으로 줄어드므로 O(log n)
- 공간: 정수 변수만 사용하므로 O(1)

## JS 구현 포인트

- `n % 2`로 현재 거리가 홀수인지 짝수인지 판별함
- 홀수일 때 `Math.floor(n / 2)`를 사용해 1을 뺀 뒤 2로 나누는 과정을 한 번에 처리함
- 매 반복에서 n을 직접 변경하므로 별도의 상태 배열이 필요하지 않음
