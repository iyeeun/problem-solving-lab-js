# [연속 부분 수열 합의 개수](https://school.programmers.co.kr/learn/courses/30/lessons/131701)

## 문제 요약

- 자연수로 이루어진 원형 수열이 주어짐
- 원형 수열에서 만들 수 있는 모든 연속 부분 수열의 합을 구함
- 중복되는 합을 제외한 서로 다른 합의 개수를 반환함

## 입력 구조

- elements: 원형 수열의 원소를 순서대로 담은 배열, 길이는 3 이상 1000 이하
- elements의 원소: 1 이상 1000 이하의 자연수

## 문제 유형 분류

- 완전탐색
- 원형 배열
- 누적합
- Set

## 사고 과정

### 1. 왜 이 유형인가

- 원형 수열에서는 배열의 끝을 지나 처음으로 이어지는 연속 구간도 확인해야 함
- 인덱스를 배열 길이로 나눈 나머지를 사용하면 끝을 지난 위치를 배열의 처음으로 되돌릴 수 있음
- 각 시작점에서 원소를 하나씩 더하면 길이 1부터 n까지의 부분 수열 합을 차례로 구할 수 있음
- 서로 다른 합의 개수만 필요하므로 모든 합을 Set에 저장하면 됨

### 2. 왜 다른 접근은 안되는가

- 각 구간을 `slice`한 뒤 매번 처음부터 합하면 같은 원소를 반복해서 더해 O(n^3)의 시간이 필요할 수 있음
- 시작점마다 합을 0으로 초기화하고 다음 원소를 누적하면 각 구간의 합을 O(1)에 확장할 수 있음
- 배열의 끝을 조건문으로 따로 처리하는 대신 나머지 연산으로 원형 인덱스를 계산함

## 문제 풀이

- [131701.js (7분 소요)](./131701.js)

```
1. elements의 각 인덱스를 연속 부분 수열의 시작점으로 선택함
2. `(i + j) % elements.length`로 원형 수열의 다음 인덱스를 구함
3. 시작점부터 원소를 하나씩 더하며 길이 1부터 n까지의 합을 계산함
4. 계산한 모든 합을 Set에 추가해 중복을 제거함
5. Set에 저장된 서로 다른 합의 개수를 반환함
```

## 해결 전략

### 알고리즘 선택 이유

- 길이가 n인 원형 수열은 시작점 n개와 부분 수열 길이 n개의 조합을 모두 확인하면 모든 연속 부분 수열을 포함함
- 같은 시작점에서는 이전 합에 다음 원소를 더해 더 긴 부분 수열의 합을 바로 구할 수 있음
- 인덱스를 n으로 나눈 나머지를 사용하면 원본 배열을 복사하지 않고도 끝에서 처음으로 이어지는 원소에 접근할 수 있음

### 자료구조 선택 이유

- Set은 같은 합이 여러 구간에서 나와도 한 번만 저장하므로 마지막 크기가 서로 다른 합의 개수가 됨
- 원본 elements 배열에 나머지 연산으로 접근하므로 원형 수열을 위한 별도 배열이 필요하지 않음

## 시간/공간 복잡도

- 시간: n개의 시작점마다 최대 n개의 원소를 누적하므로 O(n^2)
- 공간: 서로 다른 합을 최악의 경우 O(n^2)개 Set에 저장하므로 O(n^2)

## JS 구현 포인트

- `(i + j) % elements.length`로 인덱스가 배열 길이에 도달하면 0부터 다시 순환하게 함
- 이전 sum에 원소 하나만 더해 같은 시작점의 부분 수열 길이를 하나씩 늘림
- `Set.prototype.add`는 중복된 값을 다시 추가해도 크기가 증가하지 않음
- `Set.prototype.size`로 서로 다른 부분 수열 합의 개수를 바로 구함
