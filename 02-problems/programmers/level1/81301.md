# [숫자 문자열과 영단어](https://school.programmers.co.kr/learn/courses/30/lessons/81301)

## 문제 요약

- 숫자의 일부 자릿수가 영단어로 바뀐 문자열을 원래 숫자로 변환함
- 영단어로 바뀌지 않은 숫자는 그대로 유지함

## 입력 구조

- s: 숫자와 숫자를 나타내는 영단어가 섞인 문자열
- s의 길이: 1 이상 50 이하
- s는 `zero` 또는 `0`으로 시작하지 않음
- 반환값: 1 이상 2000000000 이하의 정수

## 문제 유형 분류

- 구현
- 문자열
- 해시 맵

## 사고 과정

### 1. 왜 이 유형인가

- 숫자 영단어는 `zero`부터 `nine`까지 10개로 고정되어 있음
- 각 영단어와 숫자의 대응 관계를 객체에 저장한 뒤 문자열 전체에서 치환하면 원래 숫자 문자열을 만들 수 있음

### 2. 왜 다른 접근은 안되는가

- 문자열을 한 글자씩 읽으며 영단어를 조립하는 방식도 가능하지만 현재 위치와 임시 문자열을 별도로 관리해야 함
- 변환할 영단어가 10개뿐이므로 각 영단어를 전체 치환하는 방식이 더 단순함

## 문제 풀이

- [81301.js (3분 소요)](./81301.js)

```
1. 각 숫자 영단어를 숫자 문자열에 대응시키는 객체를 만듦
2. 객체의 항목을 순회하며 s에 포함된 같은 영단어를 모두 숫자로 치환함
3. 치환이 끝난 문자열을 숫자로 변환해 반환함
```

## 해결 전략

### 알고리즘 선택 이유

- 가능한 영단어가 10개로 고정되어 있어 모든 영단어를 한 번씩 치환해도 충분히 빠름
- `replaceAll`을 사용하면 같은 영단어가 여러 번 등장해도 한 번에 모두 변환할 수 있음

### 자료구조 선택 이유

- 객체를 사용하면 영단어와 숫자 문자열의 대응 관계를 명확하게 표현할 수 있음
- `Object.entries`로 키와 값을 함께 순회해 치환 대상과 결과를 바로 사용할 수 있음

## 시간/공간 복잡도

- 시간: s의 길이를 n이라 할 때 10개의 영단어마다 문자열을 순회하므로 O(10n), 즉 O(n)
- 공간: 치환된 문자열을 생성하므로 O(n)

## JS 구현 포인트

- `String.prototype.replaceAll`로 문자열에 같은 영단어가 여러 번 있어도 모두 치환함
- `Object.entries`의 구조 분해 할당으로 영단어와 숫자 문자열을 함께 꺼냄
- 단항 `+` 연산자로 치환이 끝난 숫자 문자열을 숫자로 변환함
